# LexiMind AI — Internationalization (i18n) & Localization Architecture

## 1. Domain Modularization
Translations are structured into isolated domain dictionaries under `apps/web/src/i18n/locales/`:
- `admin.ts`: Admin operations, headers, command palette.
- `finance.ts`: Financial metrics, MRR, ledger tables, currency formats.
- `feedback.ts`: Feedback triage, roadmap statuses, bug categories.
- `support.ts`: CSKH tickets, SLAs, agent notes.

## 2. Parity & Validation Standard
- Automated verification script: `scripts/check-translations.js`.
- Verifies 100% key parity across `en` and `vi` locales.
- Continuous CI integration ensures missing keys fail builds before deployment.
